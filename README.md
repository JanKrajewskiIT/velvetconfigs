# VelvetConfigs

Shared development and build tooling presets for Solid 2 applications and libraries.

The presets require `solid-js` 2 and `@solidjs/web` 2. When upgrading a Solid 1
project, migrate its components and any consumer-supplied Vite plugin options.
See the [Solid 2 migration guide](https://docs.solidjs.com/migration/from-solid-1/).

Documentation: [Recron project docs](https://docs.bluebraces.online/projects/velvet-configs/).

Source scanning and scanner upgrades: [security controls](security/README.md).
